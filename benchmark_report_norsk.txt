```python
def er_primtall(n):
    # Primtall er større enn 1 og har bare 2 og deres mellomrom som dele.
    if n < 2:
        return False
    for i in range(2, n // 2 + 1):
        if n % i == 0:
            return False
    return True

# Test funksjonen
print(er_primtall(7))  # returnerer True
print(er_primtall(8))  # returnerer False
```

1. **Kontroller om tallet er mindre enn 2**: Primtall må være mindre enn 2. Dette returnerer `False` for alle tall under 2.

2. **For-loop**: For hver tallet mellom 2 og tallet dividede med 2 plus 1, sjekker om det er et dele av tallet. Dette gjør at primtall må være stortere enn 1 og bare ha 2 og deres mellomrom som dele.

3. **Returnererer True**: Hvis det ikke har noen dele mellom 2 og tallet dividede med 2 plus 1, returnerer funksjonen `True`.

4. **Returnererer False**: Hvis det har noen dele mellom 2 og tallet dividede med 2 plus 1, returnerer funksjonen `False`.

```python
def er_primtall(n):
    # Sjekk om tall er mindre enn 2, som ikke er primtall
    if n <= 1:
        return False
    # Sjekk om tall er 2, som er det eneste partall som er primtall
    if n == 2:
        return True
    # Sjekk om tall er et oddetall, siden bare 2 er et partall som er primtall
    if n % 2 == 0:
        return False
    # Sjekk om tallet har noen faktorer mindre enn det, utelukkende 1 og det tallet selv
    for i in range(3, int(n**0.5) + 1, 2):
        if n % i == 0:
            return False
    return True
```

### Forklaring av funksjonen:

1. **`if n <= 1:`** - Hvis tallet er mindre enn eller lik 1, så er det ikke et primtall, så vi returnerer `False`.

2. **`if n == 2:`** - 2 er det eneste partall som er et primtall, så hvis tallet er 2, returnerer vi `True`.

3. **`if n % 2 == 0:`** - Om tallet er et partall (utelukkende 2) og ikke 2, så er det ikke et primtall, så vi returnerer `False`.

4. **For-løkke fra 3 til `int(n**0.5) + 1, steg med 2**:** - Her sjekker vi om tallet har noen faktorer mindre enn det tallet selv, men kun for oddetall (siden vi allerede har sjekket partall). Vi begynner fra 3 og går opp til kvadratroten av tallet (plusser 1 for å inkludere det) for å optimere koden, fordi hvis tallet har en faktor større enn kvadratroten, må det også ha en faktor mindre enn kvadratroten.

5. **`if n % i == 0:`** - Hvis tallet er delelig med noen av disse verdien, så er det ikke et primtall, så vi returnerer `False`.

6. **`return True`** - Hvis vi har gjennomført alle disse sjekkene uten å finne noen faktorer, så er tallet et primtall, og vi returnerer `True`.

Denne metoden er effektiv for de fleste primtall, men kan bli litt langsom for very store tall.
