Innstillinger

Modeller hentes automatisk fra models/-mappen. Legg til flere .gguf-filer der, eller last ned via knappen under.
Hele dokumentbiblioteket, uansett hvilke samtaler dokumentene er koblet til. Sletting her fjerner dokumentet permanent fra alle samtaler.
En skill er en fil i skills/-mappen som kan definere flere skråstrek-kommandoer. Brukeren skriver f.eks. /humanize først i en melding, og kommandoens instruksjon legges til for det ene svaret. Formatet:
Skriv kommandonavn og beskrivelser på engelsk – modellene følger engelske instruksjoner mest presist.
# Skill name (shown here)

## /command  Short description shown in the / menu
The instruction the model follows for this command.
Everything down to the next "## /..." (or end of file) belongs to it.

## /next-command
Description on its own first line if not on the ## line.

The instruction for this one.
16384 tokens
Større kontekst bruker mer minne og kan gjøre modellene tregere å starte. Endring krever at modellen lastes på nytt.
6 tråder
Sett til omtrent antall fysiske CPU-kjerner på maskinen din.
Nullstiller kontekstvindu, tråder og alle modell-innstillinger (visningsnavn, aktiv-status, CPU/GPU) til standard. Samtaler, dokumenter og skills beholdes.
